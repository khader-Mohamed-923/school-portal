┌────────────────────────────────────────────────────────────────────────────┐
│  DATA FLOW                                                                 │
└────────────────────────────────────────────────────────────────────────────┘

1. You open browser → http://localhost:5001
                      ↓
2. Students Container receives request
                      ↓
3. Container connects to: Server=sqlserver;Database=SchoolPortalDB
                      ↓
4. Data saved in Docker SQL Server Container
                      ↓
5. Data persists in Docker volume: sqlserver-data

│  KEY DIFFERENCES                                                           │
└────────────────────────────────────────────────────────────────────────────┘

LOCAL SQL SERVER:
  Server: .
  Port: 1433 (default)
  Access: Direct
  Data: ❌ Empty (not used by Docker containers)

DOCKER SQL SERVER:
  Server: localhost,1433  (from outside Docker)
          sqlserver       (from inside Docker)
  Port: 1433 (mapped)
  Access: Through Docker port mapping
  Data: ✅ All your application data is here!

docker-compose.yml (ACTUAL CONFIG):
  ConnectionStrings__DefaultConnection=
    Server=sqlserver;Database=SchoolPortalDB;User Id=sa;Password=YourStrong!Passw0rd
           ↑                  ↑
           │                  └─ Single database for both services
           └─ Docker container hostname
