🚀 HOW TO USE
================================================================================

RECOMMENDED METHOD:
1. Double-click: git-commit-all.bat
2. Choose option 1 (single commit) or 2 (structured commits)
3. Enter 'y' when asked to push
4. Enter your GitHub repository URL
5. Done!

ALTERNATIVE METHOD:
1. Double-click: git-quick-commit.bat
2. Enter your commit message (or press Enter for default)
3. Enter 'y' to push
4. Done!

MANUAL METHOD:
1. Open Command Prompt in project folder
2. Run: git init
3. Run: git add .
4. Run: git commit -m "feat: implement SchoolPortal microservices"
5. Run: git remote add origin YOUR_GITHUB_URL
6. Run: git push -u origin main

================================================================================
🆘 TROUBLESHOOTING
================================================================================

PROBLEM: Script doesn't run
SOLUTION: Right-click → "Run as Administrator"

PROBLEM: "Git is not installed"
SOLUTION: Install Git from https://git-scm.com/

PROBLEM: "Permission denied"
SOLUTION: Use HTTPS URL instead of SSH

PROBLEM: "failed to push"
SOLUTION: Check repository URL and authentication

PROBLEM: "remote origin already exists"
SOLUTION: Run: git remote remove origin
