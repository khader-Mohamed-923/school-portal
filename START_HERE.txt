┌────────────────────────────────────────────────────────────────────────────┐
│  STEP 1: CREATE GITHUB REPOSITORY                                          │
└────────────────────────────────────────────────────────────────────────────┘

  1. Go to: https://github.com/new
  2. Repository name: SchoolPortal
  3. Description: Microservices-based school management system
  4. Choose: Public or Private
  5. ⚠️  DON'T check "Initialize with README"
  6. Click: "Create repository"
  7. Copy your repository URL (looks like):
     https://github.com/YOUR_USERNAME/SchoolPortal.git


┌────────────────────────────────────────────────────────────────────────────┐
│  STEP 2: RUN THE AUTOMATION SCRIPT                                         │
└────────────────────────────────────────────────────────────────────────────┘

  📁 Double-click this file:
  
     ► git-commit-all.bat
  
  The script will:
  ✓ Initialize Git repository
  ✓ Let you choose commit strategy
  ✓ Create commits automatically
  ✓ Push to GitHub


┌────────────────────────────────────────────────────────────────────────────┐
│  STEP 3: CHOOSE YOUR COMMIT STRATEGY                                       │
└────────────────────────────────────────────────────────────────────────────┘

  When the script asks, choose:
  
  [1] Single Commit (RECOMMENDED FOR BEGINNERS)
      ✓ Fastest method
      ✓ All changes in one commit
      ✓ Clean, simple history
      ✓ Takes 30 seconds
  
  [2] Structured Commits (FOR DETAILED HISTORY)
      ✓ 13 separate commits
      ✓ Shows project evolution
      ✓ Professional commit history
      ✓ Takes 1 minute


┌────────────────────────────────────────────────────────────────────────────┐
│  STEP 4: PUSH TO GITHUB                                                    │
└────────────────────────────────────────────────────────────────────────────┘

  When asked "Push to remote?":
  
  1. Type: y
  2. Paste your GitHub repository URL
  3. Wait for upload to complete
  4. Done! ✅


┌────────────────────────────────────────────────────────────────────────────┐
│  ALTERNATIVE: QUICK COMMIT                                                 │
└────────────────────────────────────────────────────────────────────────────┘

  For a simpler experience:
  
     ► git-quick-commit.bat
  
  This script:
  ✓ Commits everything with one message
  ✓ Asks if you want to push
  ✓ Super fast and simple


┌────────────────────────────────────────────────────────────────────────────┐
│  MANUAL METHOD (IF SCRIPTS DON'T WORK)                                    │
└────────────────────────────────────────────────────────────────────────────┘

  Open Command Prompt here and run:
  
  git init
  git add .
  git commit -m "feat: implement SchoolPortal microservices architecture"
  git remote add origin https://github.com/YOUR_USERNAME/SchoolPortal.git

┌────────────────────────────────────────────────────────────────────────────┐
│  🆘 TROUBLESHOOTING                                                        │
└────────────────────────────────────────────────────────────────────────────┘

  PROBLEM: "Git is not installed"
  SOLUTION: Download from https://git-scm.com/
  
  PROBLEM: "Permission denied"
  SOLUTION: Use HTTPS URL (not SSH)
  
  PROBLEM: "failed to push"
  SOLUTION: Check repository URL and try again
  
  PROBLEM: Script won't run
  SOLUTION: Right-click → "Run as Administrator"
